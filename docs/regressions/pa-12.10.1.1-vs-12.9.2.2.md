# PA 12.10.1.1 versus PA 12.9.2.2 on Ubuntu 24.04

## Classification

**CONTRACT_COMPATIBLE_MINOR_CHANGES.** The automated PA 12.10.1.1 run completed installation, token auto-registration, Harmony login, Agent Services connection, synchronization and local service health on the same Ubuntu 24.04.5 VM used for the earlier PA 12.9.2.2 baseline. No required contract change or functional regression was observed. This is a functional result with a 2-vCPU test exception, not production sizing approval.

| Contract item | PA 12.9.2.2 baseline | PA 12.10.1.1 live observation | Classification |
| --- | --- | --- | --- |
| OS and architecture | Ubuntu 24.04.5, amd64 | Ubuntu 24.04.5, amd64 | Unchanged |
| Package dependencies | `odbcinst`, `unixodbc` | `odbcinst`, `unixodbc`; `unzip` preinstalled by workflow | Unchanged |
| Native package and unattended install | `jitterbit-agent` `.deb`, `silent_install` | `jitterbit-agent` 12.10.1.1 amd64, `silent_install=1 dpkg --install` exit 0; `install ok installed` | Compatible |
| Install root and JRE | `/opt/jitterbit`, bundled JRE | Same root, `/opt/jitterbit/jre/bin/keytool` and `jre/lib/security/cacerts` present | Unchanged |
| Registration lifecycle | Native `register.json` becomes encrypted `credentials.txt` | One restart, auto-registration complete, credentials created, `register.json` absent after success | Unchanged |
| Harmony and Agent Services | Authenticated and connected | Authenticated, logged in, connected, request flow started | Unchanged |
| Synchronization and heartbeat | Synchronization observed; heartbeat supporting | Synchronization completed at 16:59:28 UTC; heartbeat started | Unchanged |
| Local services | ProcessEngine, Scheduler, FileCleanup, VerboseLogShipper | Same four services and `All services are running` | Unchanged |
| Runtime timing | Baseline evidence not normalized for direct duration comparison | 55.0 seconds restart to log, 175.3 seconds runtime poll, 268 seconds end to end | New measured evidence; no performance conclusion |

The classification uses the [PA 12.9.2.2 live contract](../../evidence/pa-12.9.2.2/ubuntu-24.04/runtime-contract.yaml) and the [PA 12.10.1.1 live contract](../../evidence/pa-12.10.1.1/ubuntu-24.04/runtime-contract.yaml).
